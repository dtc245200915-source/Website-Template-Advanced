# Website Template Advanced

Bài thực hành tạo Website Template có giao diện đẹp mắt bằng HTML và CSS.

## Thành phần
- Header có ảnh nền và hiệu ứng blur
- Navigation Menu cố định khi cuộn
- Card Layout sử dụng CSS Grid
- Hiệu ứng hover
- Footer 2 cột
- Responsive cơ bản

## Chạy bài
Mở `index.html` bằng Live Server trong Visual Studio Code.
